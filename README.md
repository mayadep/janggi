# 장기 JangGi (웹)

`index.html`을 더블클릭해 브라우저(크롬/엣지)로 열면 바로 실행됩니다. 설치나 빌드가 필요 없습니다.

- 위쪽은 상대, 아래쪽은 나. 한 수는 15초 안에 둬야 하며, 넘기면 둘 수 있는 수 중 하나를 무작위로 자동으로 둡니다(지지 않고 계속 진행). 초·한은 매 판 무작위로 정해지고 초가 먼저 둡니다. 한은 덤 1.5점.
- 규칙: 궁성 대각선, 포는 포를 넘거나 잡을 수 없음, 마·상 멱(길막힘), 졸의 궁성 대각 전진, 장군을 피하지 않는 수 금지, 외통이면 종료, 한 수 쉼 가능. 200수가 넘거나 양쪽이 연속으로 쉬면 점수(차13 포7 마5 상3 사3 졸2)로 판정.
- 등급: 18급부터 1급, 1단부터 9단. 50점마다 한 등급(Elo 방식). 기록은 브라우저 localStorage에 저장.
- 매칭: 대국 시작 후 5초가 지나면 ±2등급 범위의 AI와 자동 매칭. AI는 등급이 높을수록 깊게 읽고 실수가 줄어듭니다.
- 빅장(궁이 마주보는 상황) 규칙은 넣지 않았습니다.

파일: `js/rules.js`(규칙), `js/ai.js`(AI), `js/rank.js`(등급), `js/game.js`(화면), `css/style.css`.
